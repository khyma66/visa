# VisaThreads brand mark

The owner supplied `limg.png` as the brand logo. The built-in image tool prepared a transparent-background master, preserving the tomato character. The original user file is unchanged.

Prompt: “Remove ONLY the exterior white background around the supplied tomato mascot and trim the huge empty margins. Keep the exact tomato design: red body, green stem, dark outline, white eye interiors, pupils, smile and proportions. Center the full intact mark on a square transparent canvas with about 5% clear padding. No text, no mockup, no drop shadow or new objects.”

Run `node scripts/build-brand-assets.mjs` to create the small local header and browser-icon files. The header uses a neutral VisaThreads wordmark; the mascot does not replace member avatars or appear as news artwork. Keep versioned filenames when changing artwork so browsers receive new icons.
